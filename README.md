
# DownloadGusta

Interface web responsiva para validar links do YouTube e selecionar
formatos MP3 e MP4.

## Tecnologias

- HTML5
- CSS3
- JavaScript
- GitHub Pages

## Como executar

Abra o arquivo `index.html` em um navegador.

## Publicar no GitHub Pages

1. Crie um repositório chamado `DownloadGusta`.
2. Envie os arquivos para a branch `main`.
3. Acesse Settings > Pages.
4. Em Build and deployment, selecione Deploy from a branch.
5. Escolha a branch `main` e a pasta `/ (root)`.
6. Salve e aguarde a publicação.

## Limitações

Esta versão valida links e permite escolher o formato.
Ela não baixa nem converte vídeos.

O processamento real exige um backend separado e compatível
com as permissões e os direitos do conteúdo.
